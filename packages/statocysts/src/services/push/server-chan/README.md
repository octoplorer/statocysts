## URL Scheme Format

### Server chan 3

Follow official documentation [here](https://doc.sc3.ft07.com/zh/serverchan3/server/api) to get the uid and sendKey.

```
server-chan://uid:sctp1234567890abcdefghijklmnopqr@v3?tags=<tag1>&tags=<tag2>&short=<short>
```

### Server chan turbo

> [!TIP]
> Recommended to use Server chan 3 instead.

Follow its [official documentation](https://sct.ftqq.com/) to get the SENDKEY.

```
server-chan://ftqq:SCT123456abcdefghijklmnopqrstuvwxy@turbo?short=<short>&noip=<1|0|true|false>&channel=<channel>&openid=<openid>
```
