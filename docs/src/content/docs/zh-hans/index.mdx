## 从安装到完成投递

```sh
pnpm add statocysts
```

```ts title="notify.ts"
import { send } from 'statocysts'

await send(process.env.SLACK_TARGET!, {
  title: '部署完成',
  body: '生产环境运行正常。',
})
```

请将完整通知目标 URL 保存在环境变量或密钥存储中。
